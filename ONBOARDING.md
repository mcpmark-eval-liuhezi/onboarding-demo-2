# Onboarding Runbook

A short day-1 runbook for new teammates. The checklist below mirrors the sub-issues
tracked in "Onboarding checklist: day-1 setup".

## Day-1 Checklist

- [ ] Set up the local development environment
- [ ] Configure SSH keys and commit signing
- [ ] Join the code review rotation

## Notes

Work through the checklist top to bottom. Each item corresponds to a sub-issue of
the parent tracking issue, so check both boxes as you go.
